# MyFitPlan MVP

Glossy, dark fitness starter-plan web app.

## Current V1
- Personalized weekly home-workout starter plan
- 5 workout days + 2 recovery/rest days
- Exercise visuals on the website and in the branded PDF
- Weekly structure repeated for the first 4 weeks
- Branded PDF generation with Download Printable Plan
- Thank-you confirmation after PDF download
- Intro price: ₹19 (Razorpay integration is still to be connected)

## Run
```bash
npm install
npm run dev
```
